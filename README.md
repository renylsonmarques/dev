# 🎯 Desafio GitHub e Markdown

## 📋 Sobre o Projeto
Este projeto foi criado como desafio para explorar colaboração no GitHub e formatação com Markdown.

## 🚀 Objetivos Alcançados
- ✅ Criar repositório público no GitHub
- ✅ Usar GitHub.dev para edições
- ✅ Colaboração entre usuários
- ✅ Utilizar Markdown para formatação
- ✅ Praticar Git branches e pull requests

## 📝 Como Contribuir
1. Faça um fork do projeto
2. Crie uma branch para sua feature (`git checkout -b feature/nova-feature`)
3. Commit suas mudanças (`git commit -m 'Adiciona nova feature'`)
4. Push para a branch (`git push origin feature/nova-feature`)
5. Abra um Pull Request

## 🔒 Segurança
Este projeto utiliza autenticação SSH para segurança nas operações Git.
